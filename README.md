# Mynx Web

浏览器里完成 qPCR 分析、TIFF 批处理与 AI 生物学解读——从原始数据到可解读报告，一个页面搞定。

## 解决的问题

科研人员处理 qPCR 数据与 TIFF 图像时，依赖 Excel 宏或手动操作，效率低、易出错、跨平台不稳定；拿到结果后还要手工撰写生物学解读报告。Mynx Web 把这些流程搬到浏览器，Windows / macOS / Linux 即开即用，无需安装。

## 目标用户

生物医学、分子生物学、药物研发等领域的研究人员与研究生。

## 技术栈

React 18 + Vite 5 + TypeScript，纯前端实现，部署于 Vercel（边缘函数处理访问统计）。无桌面端依赖。

## 核心功能

### 1. qPCR 分析

- **数据转换**：原始 Ct 值自动转置为按样本分组，缺失值标黄，自动检测基因名。
- **相对表达量计算**：支持相对内参（2^-ΔCt）与相对对照（ΔΔCt）两种方法；可设重复次数、参考基因、对照组、柱状图颜色。
- **原生 Excel 图表**：为每个基因生成含误差棒的柱状图（直接注入 xlsx XML，非图片），并自动产出 `Summary_All_Genes` 汇总表。
- **自动暂存**：结果含图表实时存入浏览器 IndexedDB，支持下载完整 xlsx。

### 2. TIFF 批处理

- **批量转 JPG**：多选 / 拖放，多页 TIFF 自动拆分，纯浏览器解码。
- **文件名水印**：可开关，支持自定义字体、字号、粗体 / 斜体、边距、内边距、背景透明度与 JPG 质量。
- 缩略图预览 + 逐张 / 批量下载，结果自动暂存。

### 3. AI 解读（InfiniSynapse）

本地先完成确定性计算（产出 `Summary_All_Genes` 矩阵），再交给 InfiniSynapse Agent 做生物学解读。

- **内置专家角色与分析框架**：数据质量评估 → 差异表达（FC>2 上调 / FC<0.5 下调）→ 通路意义（PI3K-AKT / MAPK / Wnt / p53 / NF-κB / TGF-β 等）→ 文献对比 → 后续实验建议。
- **精简传输**：只传 Gene / Group_Name / Average / Stdev 四列矩阵，省 token。
- **限制轮次**：主 Agent 8 轮 / 子 Agent 4 轮；界面仅展示 Agent 操作状态流，不显示思考过程。

## InfiniSynapse API 使用方式

API Key 仅保存在浏览器 **localStorage**（不上传服务端，避免 Vercel Function 超时），并提供「测试连通」按钮验证有效性。

**提交流程**：前端建立 SSE 连接接收 Agent 操作消息 → `POST` 提交表达矩阵与分析需求 → Agent 在其工作区生成 `report.md`（明确指示不生成 PDF）→ 前端拉取 Markdown 内容渲染。

**报告导出**：调用浏览器原生打印对话框（A4 版式 HTML），用户可「打印为 PDF」导出，或下载 Markdown 源码；报告同时自动暂存到 IndexedDB。

## 附加体验

- 实时天气（Open-Meteo，免 Key，IP 定位）、访问统计面板（边缘函数 + KV 存储）。
- 多套主题配色、IndexedDB 文件管理面板、侧边栏导航。
- 全程数据留在浏览器本地，刷新不丢失。

## 使用场景

1. **qPCR 出图 + 解读一条龙**：导入 Ct 值 → 转换 → 计算相对表达量 → 生成含误差棒的 Excel → 上传汇总表到「AI 解读」→ 获得结构化生物学报告并导出 PDF。
2. **显微镜图像归档**：把多页 TIFF 批量转成带文件名水印的 JPG，方便插入论文或发给同组。
3. **移动端临时查看**：手机浏览器打开即可查看暂存的 Excel / 报告，无需安装软件。
